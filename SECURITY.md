# Security

ERETrace is research instrumentation that loads native code into the profiled
process. Use workloads, binaries and probe definitions you trust, on a machine
where you are authorized to instrument the GPU. Model weights and third-party
SDKs are obtained separately. SHA-1 in the inherited frontend is a filename key;
release integrity checks use SHA-256.

For a sensitive report, use the corresponding-author contact listed in the paper
rather than posting credentials or private traces in a public issue. Ordinary
reproducible bugs can be reported through GitHub Issues with redacted logs.
