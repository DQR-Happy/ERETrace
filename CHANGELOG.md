# Changelog

## v1.0.0 — 2026-11-14

First public release accompanying the accepted ISPA 2026 paper.

- Lossless SM/CTA execution-reference encoding and checked raw recovery.
- Bounded asynchronous collection, exact-length transfer planning and writer ownership.
- Serial raw, asynchronous raw, field-aware nvCOMP and SM-only controls.
- B16 adapter, document-QA case, NVBit integration and XTrace/PTX sparse/ERE integration.
- Separate variable-event capacity-analysis prototype and correctness tests.
- Pinned external frontend bootstrap with base/result SHA-256 verification.
- Public installation, reproduction, provenance and dependency documentation.
- ERETrace project branding, repository homepage and release integrity manifest.

The private submission snapshot remains unchanged. Public portability changes
are recorded in the new release history; retained paper results are not new runs.
