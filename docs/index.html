Full installation guide ↗

Start with CPU correctness tests. Bootstrap fetches the pinned Neutrino dependency, applies our patches, and verifies the assembled runtime with SHA-256.

For CPU validation
Python 3.10–3.12, Git, C compiler
For capture
Linux, NVIDIA driver + CUDA Toolkit
For inference
Pinned llama.cpp + licensed GGUF model

Model weights and vendor SDKs are installed separately. The neutrino import namespace remains compatible.

source .venv/bin/activate
